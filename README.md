# Petal & Page

A themed bullet journal for the browser: ten ready-made spreads (year, month, week, day, habits, mood, budget, savings, books, travel) in four hand-lettered themes.

- `index.html`: landing page
- `app/index.html`: the journal (entries are saved in each visitor's browser; Export → Back up journal saves a copy)

Served with GitHub Pages from the `main` branch root.
